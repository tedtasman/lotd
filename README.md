# Lottery of the Day

Generates 2 [UUIDS](https://en.wikipedia.org/wiki/Universally_unique_identifier). If they're the same, you win. [Apologizes](https://mybadbro.stevemccroskey.com) if you lose.

## Installation
### Default: 

```bash
curl -fsSL https://raw.githubusercontent.com/tedtasman/lotd/main/remote-installer.sh | bash
```
*Don't execute code you haven't read or don't trust!*

### Developer:

```bash
git clone https://github.com/tedtasman/lotd.git
cd lotd
./install
```
